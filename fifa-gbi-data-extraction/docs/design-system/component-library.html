FIFA GBI design system

One accent, one scale, one meaning per colour.

Proposal for review. Every component below replaces two to six existing variants in the app. The rule that drives it: colour means decision state, never category. Navy is the only accent. Green, red and amber are reserved for what a reviewer decided. Everything else is neutral.
