FIFA GBI workspace

Proposed design system

Every component below, as it renders today and as it would render after the change. Nothing has been implemented yet. Mark the ones you want and I will build those.

One accent: FIFA navy. Colour reserved for decisions. Five type sizes. Four radii. Two elevations.

The app uses 16 colour families. Because no rule assigns meaning, the same state wears a different colour on each screen: flagged is amber in title and abstract, rose in full text, rose in extraction, and #ef4444 in the progress donut.

Worth knowing. Your current include and exclude marks (emerald and rose) sit at a colour difference of 5.8 for red-green colour blindness, which is close to indistinguishable. The new pair scores 11.5, and every state also carries an icon and a word, so colour is never the only signal.

18. Spacing and density

Panel padding currently varies between 12, 16, 20, 24, 32 and 40px on the same class of container, and heroes use four different responsive padding ladders. The proposal puts everything on a 4px grid with three container paddings.

After

Table and list rows: 44px minimum, which is also the touch target floor.

Accessibility, while we are here. The app currently has 16px checkboxes, 24 to 32px icon buttons, a 28px approve and decline pair in the extraction field editor, and several controls at roughly 26px. All of these move to a 44px touch target. The extraction field editors, the reviewer note fields and both search inputs also gain real labels, which they do not have today.

19. Dark mode

Dark mode is currently produced by roughly 900 lines of forced overrides in the stylesheet, matching on substrings of class names. The proposal derives it from the same tokens, so it needs no overrides at all.
