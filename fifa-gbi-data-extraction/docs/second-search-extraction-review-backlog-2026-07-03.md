# Second Search Extraction Review Backlog (Backlog 2)

Scope: extraction work for records from `Second search - Ishanka - 2026-05-26`. Batches 001-006 began under the temporary AI-plus-one-human bridge on 2026-07-03. That bridge is closed: full-text screening is now complete with two human reviewers, and all new batches must use records legitimately promoted to the live extraction phase.

Queue state: use the live extraction phase as the source of truth. Historical per-row notes about a pending second human vote describe the state when those rows were processed; they are not a current selection rule. This backlog currently covers the first six five-paper extraction batches.

Review state:
- `⏲️ pending_review`: staged, extracted, or tagged by Codex and still needs manual check
- `✅ reviewed_complete`: reviewed by Abdel and done
- `needs_follow_up`: reviewed, but something still needs changing

Workflow:
- Use 5-paper batches.
- When Abdel asks for the `next batch`, select any five unprocessed records currently in the live extraction phase. A record may use an attached PDF or other available full text.
- Do not use AI-plus-one-human screening state, old bridge manifests, or study-ID order as eligibility rules. Live extraction-phase promotion after two-human full-text screening is the eligibility gate.
- Before extraction, confirm the record has not already been processed and is not assigned to another reviewer. Assign the selected record to AbdelRahman Babiker and set its live status to `processing`.
- After extraction and the required review gate, keep the live status as `processing`, add the record to the next numbered batch in this file, and mark it `⏲️ pending_review`.
- Keep live papers in `processing` while awaiting Abdel review.
- If extraction prep finds a clearly ineligible or already-processed paper, skip it, document why when material, and replace it with another unprocessed record from the live extraction phase.
